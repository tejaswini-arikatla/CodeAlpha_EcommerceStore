# E-Commerce Store

## Project Description

A full-stack E-Commerce Store developed using:

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB Atlas

## Features

* User Registration
* User Login
* Product Listing
* Product Details
* Add To Cart
* Remove From Cart
* Delivery Address
* Place Order
* Order Summary
* Authentication
* MongoDB Database

## Live Demo

Frontend: Netlify

Backend: Render
